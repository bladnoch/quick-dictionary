# 선택 사전 · NAVER & Google v1.1.3

선택한 단어는 네이버 영어사전, 문장은 Google 번역으로 분기하는 독립 제작 Chrome Manifest V3 확장 프로그램입니다. Google 번역 확장의 선택 번역 방식 두 가지를 재구현했습니다.

- **번역 버튼 먼저 표시**: 드래그한 내용 옆의 버튼을 누르면 조회합니다. 기본 모드이며, 누르기 전에는 외부 조회를 하지 않습니다.
- **선택 즉시 자동 표시**: 드래그를 마친 뒤 기본 250ms 후 바로 조회하고 결과를 표시합니다.

## 설치

1. ZIP의 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. `manifest.json`이 들어 있는 **extension 폴더**를 선택합니다.
6. 사용할 웹페이지를 **새로고침**하고 단어나 문장을 선택합니다.

설정은 도구 모음의 확장 아이콘으로 엽니다. `START_HERE.html`을 열면 자세한 한국어 안내를 볼 수 있습니다. 이 배포본은 Chrome 웹 스토어 등록본이 아닌 압축해제 설치용 소스 패키지입니다. 별도 빌드·서버·API 키 입력은 필요하지 않습니다. 설치한 폴더는 삭제하지 마세요.

## 기본 분기

| 선택 내용 | 조회 서비스 |
| --- | --- |
| `warehouse`, `don't`, `state-of-the-art` | 네이버 영어사전 |
| `data warehouse`, `The warehouse is ready.` | Google 번역 |
| 숫자·기호만 선택, 5,000자 초과 | 조회하지 않음 |

공백 기준 한 단어를 사전으로 보내는 규칙입니다. 문법 분석을 통한 문장 판별은 아닙니다. 설정에서 두 단어/세 단어 이하를 사전으로 보내도록 바꿀 수 있고, 결과창 또는 우클릭 메뉴에서 서비스를 직접 지정할 수 있습니다.

## v1.1.3 · 바깥 클릭으로 닫은 말풍선 재등장 수정

- 말풍선 바깥을 클릭하면 해당 선택에 대한 말풍선을 닫힌 상태로 유지합니다. 선택 강조를 지우거나 편집 내용을 변경하지 않습니다.
- 마우스를 놓을 때 남아 있는 이전 선택이나 늦게 도착한 선택 이벤트를 새 조회로 처리하지 않습니다. 표시 대기 중이거나 조회 중인 말풍선을 닫아도 이전 결과가 다시 나타나지 않습니다.
- 같은 단어를 새로 드래그하거나 다른 단어·다른 위치의 같은 단어를 새로 선택하면 다시 사용할 수 있습니다. 명시적인 단축키 조회도 유지합니다.
- 버튼 확인 모드와 자동 조회 모드 모두에 적용합니다. 기존 권한과 조회 서비스는 그대로 유지합니다.

기존 코드에 회귀 테스트를 적용해 바깥 클릭 뒤 재등장하는 세 가지 경우를 재현했고, 수정 후 전체 120개 테스트를 통과했습니다. 실제 Chrome 화면에서의 검증은 포함하지 않습니다.

## v1.1.2 · 확장 연결 오류 구분과 복구 안내

v1.1.1의 “확장 프로그램 연결이 끊겼습니다” 문구는 모든 메시징 예외를 하나로 표시했습니다. 이 문구만으로 업데이트 후 만료된 페이지 연결인지, 응답 수신 실패인지, 다른 예외인지 확정할 수 없습니다.

- 연결이 만료된 경우 `CONTEXT_INVALIDATED` 코드와 **이 페이지 새로고침** 버튼을 표시합니다. 반복해도 복구되지 않는 조회 재시도 버튼은 표시하지 않습니다. 페이지는 자동으로 새로고침하지 않습니다.
- 응답을 받을 상대가 없거나 메시지 채널이 닫힌 일시적인 오류는 읽기 전용 요청에 한해 150ms 뒤 한 번 재시도합니다. 외부 사이트 열기는 재시도하지 않습니다.
- 말풍선의 **오류 상세**에서 Chrome이 반환한 메시지를 확인할 수 있습니다. 응답 오류와 실제 네이버·Google 조회 오류를 구분합니다.
- 확장 설정 하단의 **연결 확인**으로 설치 버전과 확장 내부 응답 여부를 확인합니다. 이 확인은 사전·번역 조회를 보내지 않습니다.

### 지금 연결 오류가 표시될 때

1. `chrome://extensions`에서 선택 사전이 켜져 있는지 확인합니다. 수정본을 설치했다면 확장 프로그램의 다시 로드를 먼저 마칩니다.
2. **조회하던 웹페이지를 새로고침**한 뒤 다시 단어를 선택합니다. 확장 관리 페이지만 새로고침하는 것으로는 기존 웹페이지의 스크립트가 갱신되지 않습니다.
3. 계속 실패하면 도구 모음의 확장 아이콘을 열어 **연결 확인** 결과를 확인합니다. 연결 정상인데 특정 웹페이지에서만 실패하면 해당 페이지를 새로고침하고, 말풍선의 오류 코드·오류 상세를 확인합니다.
4. 연결 확인 자체도 실패하면 확장 관리의 **오류** 항목에서 시작 오류를 확인합니다. v1.1.2의 실제 사용자 환경 원인은 이 진단 결과 없이 확정하지 않습니다.

이미 만료된 이전 스크립트는 새 ZIP을 내려받는 것만으로 복구되지 않습니다. 새 확장을 로드한 뒤 해당 웹페이지를 새로고침해야 합니다.

## v1.1.1 · 편집 영역과 말풍선 위치 수정

- 노션 같은 `contenteditable` 편집기, 일반 입력창과 여러 줄 입력창의 선택 텍스트를 기본으로 지원합니다. 입력하는 동안에는 조회하지 않고 선택했을 때만 동작합니다.
- 마우스·키보드 이벤트와 함께 `selectionchange` 및 입력창의 `select` 이벤트를 감지합니다. 편집기가 드래그 직후 선택을 해제하더라도 드래그를 마친 순간의 선택 내용을 사용합니다.
- 빈 사각형·0 너비·유효하지 않은 숫자·화면 밖 좌표를 제외합니다. 여러 줄·역방향 드래그는 마우스를 놓은 줄에 가깝게 표시합니다.
- 좌표를 읽을 수 없을 때에는 실제 마우스 위치나 선택 요소를 사용합니다. 사용하지 않은 가짜 `(32,32)` 좌표를 사용하던 처리를 제거했습니다.
- 긴 결과의 높이를 선택 영역 주변 공간에 맞추고, 스크롤과 화면 확대 시 좌표를 갱신합니다. 열려 있는 Shadow DOM 편집기의 선택 범위도 지원되는 API로 읽습니다.
- **기존 설정 변경:** v1.1.0까지 저장된 입력창·편집 영역 제외 설정은 이번 업데이트에서 한 번 해제합니다. 이후 세부 설정에서 **입력창·편집 영역에서는 자동 조회하지 않기**를 직접 켜면 그 선택을 계속 유지합니다. 이 옵션을 켠 상태에서도 명시적인 단축키 조회는 가능합니다. 비밀번호·인증번호 필드는 제외합니다.

실제 노션 계정에서 실행한 시험은 아닙니다. 편집기와 선택 API를 모의한 회귀 테스트 범위 및 직접 확인 절차는 `VALIDATION.md`와 `practice.html`에 있습니다. Canvas에 그린 글자처럼 브라우저가 선택 텍스트를 제공하지 않는 편집 방식은 지원하지 않습니다.

## v1.1.0 개선 사항

- 지원되는 Chrome에서는 말풍선을 브라우저의 최상위 표시 계층에 올려 페이지 요소에 가려지지 않도록 했습니다. 미지원 환경에서는 고정 위치 말풍선을 유지합니다.
- 웹페이지 스타일과 말풍선 스타일을 분리하고, 다크 모드·고대비·동작 줄이기 설정을 반영했습니다.
- 설정 화면의 글자·버튼 크기와 키보드 포커스 표시를 개선했습니다. 키보드로 실행한 결과를 닫으면 원래 위치로 포커스를 돌려줍니다.
- 자동 조회/버튼 확인 모드, 단어/문장 분기, 조회 실패 시 새 창을 자동으로 열지 않는 동작을 유지했습니다.
- GoogleChrome/modern-web-guidance의 확장 프로그램·접근성·Popover 지침을 참고했습니다. 요청한 `npx modern-web-guidance@latest install --choose`는 자동 승인 검토의 용량 오류로 완료되지 않아 공식 저장소 문서를 직접 읽어 적용했습니다. 설치 성공으로 표시하지 않으며, 적용 출처와 범위는 `MODERN_WEB_GUIDANCE.md`에 기록했습니다.

## v1.0.1에서 수정한 연결 문제

- 선택 조회에 실패할 때 새 창을 자동으로 열던 동작을 제거했습니다.
- 이전 버전의 작은 창/자동 전환 설정이 남아 있어도 말풍선 조회로 처리합니다.
- 네이버 상세 사전 요청의 참조 정보와 Origin 처리를 수정했습니다.
- 네이버 상세 조회가 실패하면 같은 단어에 대한 네이버 사전 요약을 말풍선에 표시합니다. 검색 제안을 원래 단어의 뜻으로 잘못 표시하지 않도록 일치하는 표제어만 사용합니다.
- Google 번역의 웹 번역 경로로 바꾸고 기존 데이터 경로를 보조 경로로 유지했습니다.
- 설정창의 직접 검색도 설정창 안에 결과를 표시합니다.
- 실패 시 오류 코드와 다시 시도 버튼을 말풍선 안에 표시합니다.

**기존 버전 교체:** 기존 확장을 끄거나 제거한 뒤 수정본의 `extension` 폴더를 로드하세요. 기존 설치 폴더에 파일을 덮어쓴다면 Chrome 확장 관리에서 해당 확장을 다시 로드해야 합니다. 사용 중인 웹페이지도 새로고침하세요. 기존 확장을 함께 켜 두면 이전 코드가 계속 새 창을 열 수 있습니다.

## 결과 표시와 외부 연결

단어와 문장 조회 결과를 웹페이지 안의 말풍선에 표시합니다. 연결 실패도 같은 말풍선에 표시하며 **드래그 조회 때문에 새 탭이나 작은 창을 자동으로 열지 않습니다.** “네이버에서 열기”, “Google에서 열기”, “작은 창”을 사용자가 직접 누를 때만 외부 페이지를 엽니다.

네이버 상세 사전 조회에는 확장 프로그램 자체의 요청에만 적용되는 헤더 규칙을 사용합니다. 네이버 상세 응답이 막히면 네이버 사전 요약 경로를 사용하며, 이때 결과에 요약임을 표시합니다. Google에는 웹 번역 요청을 보내고 실패하면 보조 데이터 경로로 재시도합니다. 각 서비스의 웹 응답을 이용하므로 서비스 정책이나 응답 형식 변경에 영향을 받을 수 있습니다.

**검증:** v1.0.1에서 실제 조회 코드로 `warehouse → 창고`, `The warehouse is ready. → 창고가 준비되었습니다.`를 외부 서비스에서 수신했습니다. v1.1.3은 같은 조회 코드를 유지하며 로직·이벤트·좌표·메시징 테스트 120개를 통과했습니다. 이번 버전에서 외부 연결을 다시 시험하지는 않았고 실제 Chrome 설치와 화면 렌더링은 이 환경에서 실행하지 못했습니다. 정확한 범위는 `VALIDATION.md`에 기록했습니다.

## 부가 기능

- 한국어 기본 번역, 영어·일본어·중국어(간체) 등 대상 언어 변경
- 사전/번역 수동 전환, 결과 복사, 공식 사이트 새 탭 열기
- 우클릭 조회와 `Alt+Shift+D` 단축키(macOS: Option+Shift+D)
- 전체 일시 중지, 사이트별 자동 동작 제외와 하위 도메인 적용
- 입력창·편집 영역 기본 지원과 자동 조회 제외 옵션, 비밀번호·인증번호 필드 제외
- 150~1,000ms 대기 시간 설정, 10분 메모리 캐시, 최대 128개 응답 재사용
- 새 선택 이후 도착한 이전 결과의 표시 방지

일시 중지/사이트 제외는 드래그 자동 감지에 적용됩니다. 사용자가 직접 실행한 우클릭/단축키 조회는 사용할 수 있습니다. 전체 페이지 번역, 단어장 동기화, 음성 재생은 포함하지 않습니다.

## 사용 가능한 페이지

일반 HTTP/HTTPS 페이지에서 동작합니다. 기존 페이지는 설치/업데이트 후 새로고침해야 합니다. Chrome 설정·웹 스토어·확장 프로그램 페이지·내장 PDF 뷰어에서는 말풍선 콘텐츠 스크립트를 실행할 수 없습니다. 해당 페이지에서 Chrome이 우클릭 선택 메뉴를 제공하는 경우에는 공식 사이트 창으로 조회를 넘깁니다.

로컬 HTML은 확장 세부정보에서 **파일 URL에 대한 액세스 허용**을 켜야 합니다. `practice.html`에 수동 확인용 문구를 넣었습니다. 또는 압축을 푼 폴더에서 아래 명령을 실행한 뒤 일반 웹페이지로 열 수 있습니다.

```bash
python3 -m http.server 8765
```

그다음 `http://localhost:8765/practice.html`을 엽니다. Google 번역 확장을 동시에 사용하면 팝업이 겹칠 수 있으므로 해당 확장의 선택 번역을 꺼 두고 확인하면 됩니다.

## 개인정보와 권한

선택 내용만 해당 조회 서비스로 전송합니다. 문서 전체나 페이지 URL을 조회 요청에 함께 보내지 않습니다. 응답 재사용용 선택 내용·결과는 서비스 워커 메모리에만 잠시 보관하며 영구 검색 기록을 저장하지 않습니다. 설정은 Chrome 로컬 저장소에, 재사용 창 식별자는 Chrome 세션 저장소에 저장합니다. 별도 분석·광고·수집 서버는 없습니다. 공식 사이트를 여는 경우에는 브라우저 기록 및 각 서비스의 정책이 적용됩니다.

- `storage`: 설정과 재사용 창 식별자
- `contextMenus`: 선택 텍스트 우클릭 메뉴
- `activeTab`: 확장 아이콘을 눌렀을 때 현재 사이트의 제외 설정 표시
- 콘텐츠 스크립트의 HTTP/HTTPS/파일 매칭: 페이지의 선택 이벤트 감지와 결과 표시
- `declarativeNetRequestWithHostAccess`: 이 확장 프로그램이 네이버 사전의 두 조회 API에 보내는 요청에만 참조 헤더를 적용하고 Origin 헤더를 제거합니다. 일반 페이지 요청, 쿠키, 인증 정보, 응답 보안 헤더는 변경하지 않습니다.
- 호스트 권한: 네이버 상세/요약 사전과 Google 웹/보조 번역의 네 고정 호스트

외부 응답은 실행 가능한 HTML로 삽입하지 않고 텍스트로만 표시합니다. 서비스 워커가 허용하는 요청 대상과 사이트 링크는 고정되어 있으며 임의 URL을 받아 조회하지 않습니다. 원격 코드를 다운로드하거나 실행하지 않습니다.

## 개발 및 테스트

Node.js 18 이상에서 별도 패키지 설치 없이 실행합니다.

```bash
node --test tests/*.test.cjs
```

테스트는 파서·분기·서비스 워커 통합·선택 이벤트의 모의 DOM 검증입니다. 실제 Chrome이나 외부 사이트를 대신하는 테스트가 아닙니다.

| 파일 | 역할 |
| --- | --- |
| `extension/manifest.json` | Manifest V3 선언 |
| `extension/shared.js` | 분기, 설정 검증, URL 생성, 문자열 처리 |
| `extension/content.js` | 드래그/키보드 선택, 버튼/말풍선, 요청 취소 |
| `extension/selection-utils.js` | 선택 영역의 좌표 검증, 화면 경계와 표시 위치 계산 |
| `extension/messaging.js` | 확장 연결 오류 구분과 읽기 요청의 제한된 재시도 |
| `extension/bubble-styles.js` | 말풍선의 격리된 로컬 스타일 |
| `extension/providers.js` | 네이버·Google 응답 처리와 제한/실패 감지 |
| `extension/background.js` | 외부 조회, 캐시, 작은 창, 우클릭·단축키 |
| `extension/popup.*` | 한국어 설정 화면 |
| `extension/welcome.html` | 한국어 사용 안내 |
| `practice.html` | 설치 후 수동 확인용 페이지 |
| `tests/*.test.cjs` | 외부 의존성 없는 모의 테스트 |
| `MODERN_WEB_GUIDANCE.md` | 공식 지침의 적용 출처와 범위 |

기능 변경 후 `chrome://extensions`에서 확장을 다시 로드하고 테스트할 페이지도 새로고침하세요.
